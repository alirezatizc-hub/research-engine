# سناریوی ویدیوی ۵ دقیقه‌ای (قابل اجرا بدون کلید)

هدف: نشان دادن یک چرخهٔ کامل «داده → سیگنال → تصمیم → سفارش (shadow) → خروج → گزارش → کنترل» با
همان کدی که در live اجرا می‌شود. هیچ کلید یا حساب واقعی لازم نیست.

## آماده‌سازی (قبل از ضبط)

```bash
cd wallex-ai-trader
pip install -r requirements.txt
python -m unittest discover -s tests -t .        # ۸۳ تست سبز
python -m wallexbot backtest                     # گزارش تازه
python -m wallexbot ui --demo                    # پنجرهٔ مرورگر روی http://127.0.0.1:8800
```

اگر می‌خواهید Replay سریع‌تر تمام شود: در پنل سرعت ۱۲۰۰–۲۰۰۰ بگذارید یا
`python -m wallexbot replay --speed 5000` را در ترمینال کنار ویدیو نشان دهید.

## ۰:۰۰–۰:۳۰ — مسئله و راه‌حل

- «ربات اسپات فقط‌خرید روی جفت‌های تومانی والکس؛ ۵ میلیون تومان سرمایهٔ مجازی در چالش.»
- «دو چالش اصلی: کارمزد ۰٫۷٪ رفت‌وبرگشت و پایان چالش که باید همه‌چیز تومان شود.»
- نشان دهید در پنل: SHADOW/REPLAY، بنر دمو، ساعت مجازی.

## ۰:۳۰–۱:۳۰ — معماری و کد

- `README.md` بخش معماری؛ فایل‌های `strategy.py` → `risk.py` → `orders.py` → `bot.py`.
- روی این جمله تأکید کنید: «بک‌تست، Replay و live از همان کد استفاده می‌کنند.»
- تب «تنظیمات»: پروفایل فعال، فیلتر ATR، سقف ریسک، دروازهٔ live (قرمز = عمداً بسته).

## ۱:۳۰–۲:۳۰ — AI واقعی

- `docs/AI_USAGE.md`: سه نقش.
- در `logs/decisions.jsonl` یک رکورد `DECISION` را نشان دهید: `ai.approve`, `confidence`, `reason`.
- یک خط از `logs/ai_calls.jsonl` (بدون کلید): مدل/تاخیر/هش پرامپت.
- تأکید: خطای AI = رد ورود؛ AI سایز را فقط کوچک‌تر می‌کند.

## ۲:۳۰–۳:۳۰ — یک معاملهٔ کامل در Replay

- داشبورد: کارت‌های equity/بازده/افت؛ نمودار؛ پوزیشن باز.
- تب «معاملات»: یک ردیف با `qty`, `entry`, `exit`, `pnl_tmn`, `exit_reason`.
- `logs/trades.csv` را در ترمینال با `column -s, -t` نشان دهید.
- اگر معاملهٔ جدیدی باز شد، تغذیهٔ تصمیم‌ها را نشان دهید (`BUY` با stop/tp و `rr`).

## ۳:۳۰–۴:۱۵ — ریسک و ایمنی

- Kill-Switch، حد روزانه، سقف پوزیشن، تسویهٔ پایان چالش.
- `python -m wallexbot selfcheck` (بدون فلگ) را نشان دهید که به‌درستی اجرا نمی‌شود/رد می‌کند مگر روی حساب واقعی.
- `python -m wallexbot safetytests` و فایل `logs/safety_tests.json` + هش کد.
- توضیح دهید چرا live قفل است و چطور باز می‌شود (`docs/RUNBOOK.md` بخش ۳).

## ۴:۱۵–۴:۴۵ — بک‌تست و قیف

- تب بک‌تست: بازده −۰٫۹۷٪، افت ۱٫۷۱٪، ۴ معامله.
- `funnel`: `atr_below_min_atr_pct=13`، `signal:dip=5`، `entries_executed=4`.
- صادقانه: «۲ روز داده کم است؛ مسیر دادهٔ ۳۰ روزه و walk-forward در `docs/REPRODUCIBILITY.md`.»

## ۴:۴۵–۵:۰۰ — جمع‌بندی

- «موتور کامل، قابل ممیزی، fail-closed و قابل کنترل از پنل؛ ادعای سود نداریم، ادعای شفافیت داریم.»
- اشاره به `docs/SCORING_MAP.md` برای نقشهٔ داوری.

## نکات ضبط

- رزولوشن 1080p، فونت بزرگ (۱۸+)، ترمینال با تم تیره و فونت monospace.
- هر بخش یک برش کوتاه؛ از حرکت موس تند پرهیز کنید.
- اگر Replay تمام شد، دکمهٔ Start را بزنید (loop خودکار فعال است).
- هرگز `.env` یا کلید را در تصویر نشان ندهید؛ در دمو کلیدی لازم نیست.
